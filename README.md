# Tymzy 🎯
 
> *"Because effort deserves entertainment."*
 
A gamified desktop productivity app built in Java Swing that rewards you with **leisure credits** for completing tasks. Log your activities, earn time credits, and spend them guilt-free on leisure activities.
 
---
 
## How It Works
 
Tymzy runs on a simple reward loop:
 
1. **Log a task** → Earn credits (in minutes)
2. **Stack up credits** → Watch your balance grow
3. **Spend credits** → Use them for guilt-free leisure time
The credit system encourages consistent productivity by making every completed task feel rewarding.
 
---
 
## Features
 
- **Home Screen** — Dark gaming-style launcher with Start, View Stats, and Exit
- **Activity Logger** — Add and delete tasks with timestamps stored in a database
- **Credit Engine** — Automatically calculates earned credits based on task description
- **Use Credits** — Redeem credits for leisure time with a single click
- **Live Credit Display** — Always shows your current credit balance in minutes
- **Alternating Row Colors** — Clean, readable activity list with custom cell renderer
- **Async DB Calls** — All database operations run on background threads via `SwingWorker` to keep the UI responsive
- **Icon Support** — Custom icons for all buttons (play, trophy, exit, tick, cross, controller, home)

## Credit Calculation
 
| Task Description Contains | Credits Earned |
|---|---|
| `"hour"` | 30 mins |
| `"30 min"` or `"30min"` | 15 mins |
| Anything else | 10 mins (default) |

## Database Setup
 
Run these SQL statements in your Oracle DB before launching the app:
 
```sql
-- Activities table
CREATE TABLE activities (
    id            NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    activity_name VARCHAR2(255) NOT NULL,
    created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
 
-- Credits table
CREATE TABLE user_credits (
    id            NUMBER PRIMARY KEY,
    total_credits NUMBER DEFAULT 0
);
 
-- Seed the credits row
INSERT INTO user_credits(id, total_credits) VALUES(1, 0);
COMMIT;
```

## Getting Started
 
### Prerequisites
 
- Java JDK 8+
- Oracle Database XE (running on `localhost:1521`)
- `ojdbc8.jar` (or compatible Oracle JDBC driver)
### Configuration
 
Open `DBHelper.java` and update your credentials:
 
```java
private static final String URL      = "jdbc:oracle:thin:@localhost:1521:XE";
private static final String USER     = "system";   // your Oracle username
private static final String PASSWORD = "orcl";     // your Oracle password
```
 
### Compile & Run
 
```bash
# Compile (add ojdbc jar to classpath)
javac -cp .;lib/ojdbc8.jar src/*.java
 
# Run
java -cp .;lib/ojdbc8.jar;src HomePage
```
 
> On macOS/Linux, replace `;` with `:` in the classpath.

## Key Implementation Notes
 
**`SwingWorker`** — Every DB call (insert, delete, fetch, credits update) runs off the Event Dispatch Thread to prevent UI freezing. Results are applied back on the EDT inside `done()`.
 
**Transactional Credits (`addCredits`)** — Uses `UPDATE` first; if no row exists, falls back to `INSERT`. Wrapped in a manual transaction with `rollback()` on failure.
 
**`useCredits`** — The SQL `WHERE total_credits >= ?` condition ensures atomicity — credits can never go negative, even under concurrent access.
 
**Custom Cell Renderer** — The activity `JList` uses a lambda-based renderer for alternating row background colors and blue highlight on selection.
